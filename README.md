# Leo Agent

一个 Android 上的 AI 助手：**能聊天、能读写文件、能跑代码、能替你操作别人家的 App。**

默认开箱即用（内置 DeepSeek 配置），装上就能对话，不需要注册账号。

> 本仓库**只发布安装包**。源代码不公开。

---

## 下载

到 [Releases](../../releases/latest) 页面下载最新的 `.apk`。

| 项目 | 要求 |
|---|---|
| 系统 | Android 8.0（API 26）及以上 |
| 架构 | arm64-v8a（绝大多数手机都是） |
| 大小 | 约 130 MB（内含完整 Python 运行时） |

安装时系统会提示「未知来源应用」，需要允许一次。

## 它能做什么

### 对话

流式输出、Markdown 渲染、代码高亮、长按选择文本、复制、重新生成、改写。
支持「思考型」模型——推理过程折叠成一行，想看再展开。

### 文件

它有一个工作区（手机 `Download/LeoAgent/workplace/`）。你可以把图片、PDF、Word、
Excel、日志、压缩包发给它，也可以让它自己读、写、删。

### 代码

App 里打包了完整的 Python 3.11 运行时（numpy / pandas / matplotlib / requests /
lxml / openpyxl / python-docx / pdfplumber …），所以「算一下这个」「画个图」
「把这份 Excel 合并了」都可以直接让它做，不需要另装环境。

也可以跑 shell 命令。

### 操作手机（可选，默认关闭）

打开「屏幕操作」并授权无障碍服务后，它能看见当前屏幕并点击：
「打开微信给张三发消息」这类事可以交给它。

这是**风险最高**的能力，所以默认关闭、需要单独授权，且在执行敏感动作前会先问你。
不想用就永远不打开，其它功能完全不受影响。

### 记忆与提醒

按工作区保存的记忆（下次聊到相关话题会自动带上），以及定时提醒。

## 首次使用

1. 打开 App，直接就能聊——内置配置不需要填任何东西。
2. 想换模型：**设置 → 模型设置**，切到「自定义」，填 Base URL / API Key / 模型名。
   任何 OpenAI 兼容的服务都可以（DeepSeek、OpenAI、通义、本地 vLLM、Ollama…）。
3. 想用它操作手机：**设置 → 屏幕操作**，打开开关并按指引授权。

---

## 关于权限

| 权限 | 用途 | 是否必须 |
|---|---|---|
| 网络 | 访问模型服务 | 必须 |
| 通知 | 定时提醒 | 可选 |
| 所有文件访问 | 读写工作区（Android 11+ 写非媒体文件需要） | 可选 |
| 无障碍服务 | 看见并点击屏幕 | 默认关闭 |
| 悬浮窗 | 任务进行时在屏幕顶部显示进度条 | 可选 |

**没有**后台定位、读取通讯录、读取短信这类权限。

## 可以和官方开发版装在一起

本仓库发布的包名是 `com.leo.agent.release`，与开发版 `com.leo.agent` 是两个独立的
App——数据、授权、通知各自独立，不会互相覆盖。

不足的是桌面图标和名字都一样，需要在「设置 → 应用」里按包名区分。

## 说明

- 这个 App 会把你的对话内容发送给你所选择的模型服务商。请自行判断内容的敏感程度。
- 「操作手机」功能会代替你点击屏幕。请只在信任的场景下开启，并在执行重要操作时
  盯着它。
- 内置的默认服务有额度限制，用不了时可以在设置里换成自己的 API Key。
